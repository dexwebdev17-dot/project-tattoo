# Atelier Tattoo - Guida alla Personalizzazione

Per creare e personalizzare il tuo sito web:

1. Clicca sul pulsante verde **Use this template** in alto a destra e seleziona **Create a new repository**.
2. Scegli un nome per il tuo progetto e salva.
3. Apri il file `.html` del template scelto e premi il tasto `.` (punto) sulla tastiera per aprire l'editor integrato.
4. Modifica i testi (nome dello studio, contatti, prezzi) e salva.
